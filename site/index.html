The order of a model, kept only where noise can't explain it.

Classical information criteria next to Fine–Hwang threshold estimators: grow the memory with the sample, studentize every statistic, clip what white noise could produce, report the last surviving lag.

Two families, one honest comparison

Information criteria score every candidate order; threshold estimators keep the last lag whose statistic survives a vanishing cut-off. tsorder computes both from one pass over the data, so they can be compared on equal footing — in accuracy and in time.

🧮

One data path

Sample autocovariance (by FFT for large lags) → Levinson–Durbin recursion. AIC, AICc, BIC, HQ, FPE, CAT and MDL, the PACF and the long AR fit all come from the same O(K²) pass — with Burg and conditional-OLS variants a flag away.

📏

Studentized by construction

The raw Fine–Hwang threshold is not scale-invariant and degrades with n. Every statistic here returns its null standard error, and every threshold lives on the studentized scale.

🔌

Pluggable statistics

PACF for AR, Bartlett-studentized ACF for MA, long-AR coefficients by Yule–Walker or OLS. The statistic and the cut-off rule are orthogonal axes of the API.

🎚️

Calibrated thresholds

BIC-like, iterated-logarithm, max-of-K and Gumbel rules. The Gumbel threshold controls the family-wise over-selection level: α = 5% means ≈ 5% false positives on white noise, verified in the tests.

🗳️

Ensembles

Majority, median, min and max over several configurations — insurance under misspecification, following the model-by-consensus idea of García-Hiernaux et al. (2012).

🦀

No dependencies

Pure Rust on the standard library, deterministic, MSRV 1.81. Errors are values (Result), never a panic on user data — ready for thin R and Python bindings.

How it works

Fine & Hwang (1979) proved the first consistent order estimator: no likelihood, no Gaussianity, no maximum order to guess. tsorder is that idea with the one repair it needed — studentization.

01

Grow the memory

Fit a long model of order p_n that increases with the sample size n.

02

One recursion

Autocovariances and one Levinson–Durbin pass give every statistic and every criterion.

03

Studentize

Each statistic is divided by its null standard error, so the threshold is scale-free.

04

Clip and report

Zero everything below τₙ; the last surviving lag is the order. The full path is returned for plotting.

Install & run

Add the crate and pass any &[f64]. Rust 1.81 or later; changes between versions in the changelog. R (extendr) and Python (PyO3) bindings are planned on top of this same core.

$ cargo add tsorder-core
// classical criteria and the default Fine–Hwang
use tsorder_core::*;

let bic = ic_order(&x, Criterion::Bic, None)?;
let fh  = fh_order(&x, FhConfig::default())?;
println!("BIC {} / FH {}", bic.order, fh.order);

// the whole studentized path, for plots
for (k, t) in fh.studentized.iter().enumerate() {
    println!("lag {} |t| {:.2}", k + 1, t.abs());
}
// MA order, level-calibrated threshold, ensemble
let ma = fh_order(&x, FhConfig {
    statistic: Statistic::AcfBartlett,
    threshold: Threshold::Gumbel { alpha: 0.05 },
    ..Default::default()
})?;

let e = ensemble_order(&x, &[
    FhConfig::default(),
    FhConfig { statistic: Statistic::LongArOls,
               ..Default::default() },
], EnsembleRule::Majority)?;

✅

Tested properties

Order recovery on long simulated AR, MA and subset-AR series; affine invariance of every statistic and criterion; empirical level of the Gumbel rule on white noise; errors instead of silent NaN.
